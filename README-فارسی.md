# Waste724 (اپ ترکیبی مشتری + راننده)

این پروژه، برخلاف دو پروژه‌ی قبلی، مستقیم به یک سایت وصل نمی‌شود. اپ اول یک
**صفحه‌ی انتخاب محلی** (طراحی‌شده در `www/index.html`) را نشان می‌دهد که از
کاربر می‌پرسد «مشتری» است یا «راننده»؛ بعد از انتخاب، همان WebView به سایت
مربوطه (`recycle.waste724.ir` یا `driver.waste724.ir`) هدایت می‌شود.

## چرا این‌طوری، نه ادغام واقعی دو سایت؟

چون این دو سایت (Recycle و Driver) دو پروژه‌ی Next.js کاملاً مستقل با
دیتابیس، سیستم لاگین و دامنه‌ی جدا هستند، ادغام واقعی کدشان در یک اپلیکیشن
نیاز به بازنویسی و یکپارچه‌سازی بک‌اندشان دارد (پروژه‌ی بزرگی جدا از
«تبدیل به اپ موبایل»). راه‌حل استاندارد و عملی برای همچین وضعیتی، یک
**اپ لانچر مشترک** است که کاربر را به سمت سایت درست هدایت می‌کند — دقیقاً
مثل خیلی از اپ‌های حمل‌ونقل که یک اپ برای «مسافر/راننده» با صفحه‌ی انتخاب
اولیه دارند.

## مراحل ساخت APK

همان مراحل پروژه‌های قبلی، این پروژه هم همون اسکریپت خودکار اصلاح
`build.gradle`ها رو داره (`npm install` خودش انجامش میده).

```powershell
cd waste724-app\mobile-app
npm install
npx cap sync android
npx cap open android
```

بعد از باز شدن Android Studio و اتمام Gradle Sync:

```
Build → Generate Signed Bundle / APK...
```

یک Keystore جدید بساز (مثلاً `waste724-app-release.jks`، alias: `waste724app`)
یا اگه ترجیح می‌دی، از یکی از Keystoreهای قبلی (Recycle یا Driver) هم می‌تونی
استفاده کنی — فقط باید alias مناسبی داخلش تعریف کنی یا از همون alias موجود
دوباره استفاده کنی (فرقی نداره، چون appId این پروژه `ir.waste724.app` است،
مستقل از دو تای دیگه).

سپس: Build Variant → **release** → تیک V1 و V2 → **Finish**

فایل نهایی:
```
android/app/release/app-release.apk
```

## آیکون و برندینگ

این نسخه از پروژه از قبل با **لوگوی واقعی Waste724** تنظیم شده:

- **آیکون اپلیکیشن (Launcher Icon)**: از روی لوگوی شما ساخته و جایگزین آیکون
  پیش‌فرض Capacitor شده — دیگه لازم نیست از `Image Asset` دستی استفاده کنی،
  مگر بخوای بعداً عوضش کنی.
- **صفحه‌ی انتخاب مشتری/راننده**: بالای صفحه خود لوگو (نماد بی‌نهایت/بازیافت)
  رو نشون می‌ده، و رنگ کارت‌های مشتری/راننده هم مستقیم از پالت لوگو گرفته شده:
  - مشتری: سبز (`#59B139` روشن → `#1C3E1D` تیره)
  - راننده: نارنجی (`#E8471D` روشن → `#A5320F` تیره)
  - آیکون‌ها هم از حالت مربعی به **دایره‌ای** تغییر کردن

فایل‌های لوگو در `www/assets/` قرار دارن:
- `logo.jpg`: فایل اصلی کامل (برای استفاده‌ی بعدی در Image Asset یا جاهای دیگه)
- `logo-icon.png`: فقط نماد (بدون متن WASTE 724)، برای بج بالای صفحه‌ی انتخاب
- `store-icon-512.png`: آیکون ۵۱۲×۵۱۲ آماده برای آپلود در پنل بازار/مایکت/Google Play

## دکمه‌ی بازگشت

این نسخه یک دکمه‌ی شناور «← بازگشت» به پروژه اضافه شده که:
- وقتی داخل سایت مشتری یا راننده هستی، بالای صفحه (گوشه‌ی چپ) نمایش داده می‌شه
- **رفتارش مرحله‌ای است**: هر بار که می‌زنیش، دقیقاً مثل دکمه‌ی Back مرورگر، یک قدم در تاریخچه‌ی همون سایت به عقب برمی‌گرده (نه این‌که همیشه مستقیم بپره به صفحه‌ی اول). فقط وقتی تاریخچه‌ی اون سایت تموم بشه (یعنی به اولین صفحه‌اش رسیدی)، با زدنش به صفحه‌ی انتخاب مشتری/راننده برمی‌گردی.
- روی خود صفحه‌ی انتخاب، خودکار مخفی می‌شه (چون نیازی بهش نیست)
- دکمه‌ی سخت‌افزاری Back گوشی هم از قبل (توسط خود Capacitor) دقیقاً همین رفتار مرحله‌ای رو داره؛ این دکمه‌ی روی صفحه فقط یک میان‌بر بصری اضافه برای کاربرهاییه که ترجیح می‌دن با دست به‌جاش استفاده کنن.

این دکمه در سطح کد بومی اندروید پیاده‌سازی شده (فایل
`android/app/src/main/java/ir/waste724/app/MainActivity.java`) چون باید روی
هر صفحه‌ای که از سایت‌های دیگر لود می‌شه هم شناور بمونه. اگه خواستی رنگ یا
متنش رو عوض کنی، همون فایل رو ویرایش کن:
- متن دکمه: خط `button.setText(...)`
- رنگ پس‌زمینه: خط `bg.setColor(Color.parseColor("#CC12341A"))`

بعد از هر تغییر در فایل‌های Java، لازم نیست `cap sync` بزنی — فقط دوباره از
Android Studio بیلد بگیر (`Build → Generate Signed Bundle / APK`).

## سفارشی‌سازی صفحه‌ی انتخاب

فایل `www/index.html` شامل دو کارت («مشتری» و «راننده») است. برای تغییر:

- **متن و آیکون هر کارت**: داخل همون فایل، دنبال `<div class="card customer">`
  و `<div class="card driver">` بگرد و متن/ایموجی رو عوض کن.
- **رنگ‌بندی**: بالای فایل، متغیرهای CSS زیر `:root` (مثل `--accent`,
  `--accent-2`) رنگ‌های اصلی رو کنترل می‌کنن.
- **آدرس سایت‌ها**: تابع `go('https://...')` توی پایین فایل، آدرس مقصد رو
  مشخص می‌کنه.

بعد از هر تغییر در `www/index.html`:
```powershell
npx cap sync android
```
و دوباره APK بساز.

## آیکون و اسم اپ

دقیقاً مثل دو پروژه‌ی قبلی:
- آیکون: راست‌کلیک روی `app` (داخل Android Studio) → `New` → `Image Asset`
- اسم اپ: `capacitor.config.ts` → مقدار `appName`، یا مستقیم
  `android/app/src/main/res/values/strings.xml` → `app_name`

## نکته درباره‌ی دکمه‌ی Back

اگه کاربر داخل سایت مشتری یا راننده باشه و دکمه‌ی Back سخت‌افزاری گوشی رو
بزنه، به‌صورت پیش‌فرض به تاریخچه‌ی قبلی WebView برمی‌گرده — که معمولاً همون
صفحه‌ی انتخاب اولیه (Customer/Driver) خواهد بود. نیازی به تنظیم اضافه نیست.

## عیب‌یابی

اگه به خطای مشابه `dl.google.com` خوردی:
```powershell
npm run fix-mirrors
```
و دوباره `File → Sync Project with Gradle Files` بزن.
