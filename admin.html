این توکن فقط یک‌بار لازمه بسازی و همیشه همینو استفاده کن. اگه هنوز نساختی، پایین صفحه راهنمای ساختش هست. توکن فقط توی همین مرورگر (روی همین گوشی/کامپیوتر) ذخیره می‌شه، جای دیگه‌ای فرستاده نمی‌شه.
راهنمای ساخت توکن (فقط یک‌بار لازمه):
۱. برو به github.com/settings/tokens/new
۲. توی Note بنویس: waste724-panel
۳. Expiration رو روی No expiration بذار (یا هرچقدر خواستی)
۴. زیر Select scopes، فقط تیک repo رو بزن
۵. پایین صفحه Generate token رو بزن
۶. توکنی که نشون می‌ده (با ghp_ شروع می‌شه) رو کپی کن و همینجا بالا پیست کن

⚠️ این توکن مثل رمز عبوره؛ برای کس دیگه‌ای نفرستش.
